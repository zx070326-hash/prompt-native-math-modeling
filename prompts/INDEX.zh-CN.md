# Prompt 按需索引

先常驻读取：

- `00-UNATTENDED_BOOTSTRAP.zh-CN.md`：定义无人值守任务、能力与最终交付。
- `01-MAIN_AGENT.zh-CN.md`：当前 Chat 的研究主持语境。
- `02-AUTONOMOUS_RESEARCHER.zh-CN.md`：仅在邀请独立研究者时发送。

`on-demand/` 中的 Prompt 不构成阶段，也不应一次全部加载。Prompt 不给 Codex 增加新的基础智力。它们分为两类：探索型 Lens 在可观察认知缺口出现、且 Codex 尚未自行处理时临时提高注意；承诺型 Lens 在研究准备对外承诺、出现真实不变量异常或发生上下文切换时进入审查准入判断。

| Prompt | 何时读取或发送 | 不应因为什么加载 |
|---|---|---|
| 类型 | Prompt | 何时读取或发送 | 不应因为什么加载 |
|---|---|---|---|
| 探索 | `MODEL_CREATION.zh-CN.md` | 需要创造可计算、可比较、可实验或可形式化检查的新模型对象 | 仅仅因为任务刚开始 |
| 探索 | `MODEL_DATA_COEVOLUTION.zh-CN.md` | 数据、实验、现实知识与当前模型发生有意义冲突 | 每次得到新指标 |
| 探索 | `INFORMATION_GAIN_ACTION.zh-CN.md` | 下一行动不清楚、研究停滞或多个行动需要取舍 | 为所有工具调用增加仪式 |
| 探索 | `REFLECTION_MIRROR.zh-CN.md` | 研究活动很多，但不确定是否产生了新数学对象或改变判断 | 固定周期复盘 |
| 探索 | `EXTERNAL_DISCOVERY.zh-CN.md` | 陌生领域、当前事实、专业数据接口或领域工具可能改变问题表征、模型、实验或关键主张 | 普通文件读写、已知代码运行、简单计算，或仅为增加引用数量 |
| 探索 | `MODEL_COMPARISON.zh-CN.md` | 多个模型、变体或局部结构需要按用途比较、选择或融合 | 强制产生多个模型后再评分 |
| 承诺 | `ADVERSARIAL_RESEARCHER.zh-CN.md` | 已观察到嵌套基线、不变量、守恒、量纲或复现关系的真实异常，且机械检查不能解释其意义 | 为制造 Agent 数量、共识或例行“唱反调” |
| 承诺 | `CLAIM_CHECK.zh-CN.md` | 准备冻结会改变最终模型、结论或决策的一组核心主张，机械重算不足以确定其证据边界 | 每个中间结论、普通措辞检查或制造形式化审批 |
| 承诺 | `DELIVERY_REVIEW.zh-CN.md` | 正式论文、报告或提交包已经生成且数学结果基本锁定，准备标记为可交付 | 研究尚未收敛、尚无渲染成品，或用写作完整性替代科学检查 |
| 承诺/切换 | `HANDOFF_RESUME.zh-CN.md` | 长任务确实要中断、跨 Chat 交接或从压缩后恢复 | 普通单回合任务、定期打卡或保存完整思维过程 |

默认一次只使用一份按需 Prompt。普通工具操作由 Codex 自主完成，不需要 Prompt 审批。探索型 Lens 若当前行动已覆盖其目的，就直接继续。承诺型 Lens 先应用 `contracts/REVIEW_GATE.zh-CN.md`：机械检查优先，低影响或不会改变判断时跳过，接纳后才生成一个有限审查信封并发送独立上下文。只保留 Lens 产生的模型、实验、证据、冲突、交付或决策变化；审查信封是该次审查的证据工件，不是 Lens 调用注册表或第二套项目状态。
