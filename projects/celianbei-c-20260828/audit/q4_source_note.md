# 问题四外部来源记录

- 来源：Wikipedia contributors, “2022 FIFA World Cup”，<https://en.wikipedia.org/wiki/2022_FIFA_World_Cup>
- 访问日期：2026-08-28；脚本用 `requests` + `pandas.read_html` 抓取小组赛表格。
- 适用范围：确认2022世界杯8组、48场小组赛的日期、球队、比分和场馆名称；不是官方接口，页面字段可能变动。
- 对判断的实际影响：提供了现实赛程的休息时间和场馆利用比较基准。页面未统一提供开球UTC和容量，脚本对缺失字段采用18:00当地/公开容量近似，并在论文中把容量匹配、黄金时段标为代理指标，不将其作为历史事实结论。
